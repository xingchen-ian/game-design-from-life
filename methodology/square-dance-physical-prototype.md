# 退休女性广场舞游戏 Physical Prototype

> 版本：v0.1  
> 用途：用桌面/身体原型测试“广场舞动作模仿 + 节奏压力 + 动作相似度判定”的核心机制  
> 方法来源：生活体验转译法 v2

---

## 1. 原型目标

这个 physical prototype 的目标不是完整模拟广场舞，也不是制作一个桌游版节奏游戏，而是验证一个最小核心循环：

> 看见目标动作 → 在节奏压力下用身体模仿 → 根据动作相似度得分 → 产生跟上、掉队、自信或尴尬的体验

需要验证的核心问题：

1. 玩家是否能从抽象动作卡快速理解动作？
2. 2拍或4拍动作序列是否能带来接近节奏游戏的反应压力？
3. 分部位评分能否稳定模拟“动作相似度判定”？
4. 玩家是否产生“跟上队伍”的广场舞体验，而不只是完成动作测试？

---

## 2. 生活体验分析

### 2.1 生活场景

退休女性参加广场舞活动，站在队伍中跟随领舞或前排成员学习动作。她需要一边听音乐节拍，一边观察动作，一边让自己的身体跟上队伍。

### 2.2 五维分析

| 维度 | 内容 |
| --- | --- |
| 动作 | 看动作、模仿、抬手、摆手、踏步、转身、跟拍、调整身体 |
| 过程 | 看到动作 → 理解动作 → 身体执行 → 跟不上/跟上 → 调整 → 继续跳 |
| 情感 | 犹豫、紧张、怕出错、跟上后的轻松、自信、融入感 |
| 空间 | 广场、队伍、前后左右有其他人，公开但相对熟悉 |
| 对象 | 领舞者、同伴、音乐节拍、身体、动作套路 |

### 2.3 核心体验

这个体验的核心不是“跳得专业”，而是：

> 在公共群体节奏中努力跟上，并在反复练习中从慌乱走向熟练和融入。

---

## 3. 情感原型

### 3.1 原型名称

**跟上队伍 / Keeping Up With the Group**

### 3.2 情感轨迹

```text
观察 → 慌乱 → 尝试模仿 → 出错/跟上 → 调整 → 融入或掉队
```

### 3.3 核心张力

| 想要 | 阻碍 |
| --- | --- |
| 想跟上大家，不想显得笨拙 | 动作来得快、身体反应慢、记不住顺序、节拍压力 |
| 想跳得漂亮 | 体力有限、动作幅度不够、协调性不稳定 |
| 想融入群体 | 出错会带来尴尬、自我意识或轻微压力 |

### 3.4 设计判断

这个原型不能只被转译成“动作对不对”。它还需要保留广场舞中的体面感、归属感、熟练感和群体同步压力。

---

## 4. 数据化抽象

### 4.1 核心变量

| 变量 | 类型 | Physical Prototype 表现 |
| --- | --- | --- |
| 节拍准确度 | 数值 | 是否在指定拍点完成动作 |
| 动作相似度 | 数值 | 头、手、脚、方向、幅度是否接近目标 |
| 记忆负担 | 难度 | 2拍或4拍动作序列是否能连续完成 |
| 体力 | 资源 | 大幅度动作消耗体力 |
| 自信/体面 | 状态 | 连续成功上升，连续失败下降 |
| 队伍同步 | 群体状态 | 多人一起做时，整体是否整齐 |

### 4.2 第一版最小可玩核心

第一版只保留四个变量：

1. **节拍准确度**
2. **动作相似度**
3. **体力**
4. **自信**

队伍同步可以作为第二轮测试加入，避免第一版规则过重。

### 4.3 机制流程图

| 项目 | 内容 |
| --- | --- |
| Goal | 在指定拍数内尽量模仿目标动作序列 |
| Challenge | 动作理解时间短、节拍压力、身体协调、体力限制 |
| Player Input | 玩家用自己的头、手、脚和身体方向完成动作 |
| Variables | 节拍准确度、动作相似度、体力、自信 |
| Feedback | 分数、成功/掉队判定、自信变化、体力消耗 |

## 5. Physical Prototype 组件

### 5.1 必需组件

| 组件 | 数量 | 说明 |
| --- | --- | --- |
| 2拍目标动作卡 | 12张 | 用于简单难度 |
| 4拍目标动作卡 | 12张 | 用于普通难度 |
| 节拍器或手机音乐 | 1个 | 提供稳定节拍 |
| 体力标记 | 每人5个 | 表示玩家当前体力 |
| 自信标记 | 每人5个 | 表示玩家当前自信 |
| 评分表 | 每张卡背面 | 裁判使用，玩家表演前不看 |

### 5.2 动作卡结构

每张动作卡分为正面和背面。

**正面：玩家可见**

- 抽象小人图或简化文字
- 2拍或4拍动作序列
- 难度标记：简单 / 普通 / 困难
- 是否属于大幅度动作

**背面：裁判可见**

- 分部位评分规则
- 满分10分
- 成功阈值
- 体力消耗说明

玩家在执行前只看正面。背面用于裁判评分，避免玩家把动作变成“按评分项考试”。

## 7. 一轮游戏流程

1. 翻开一张目标动作卡，玩家只看正面。
2. 节拍器开始，玩家有1个预备拍观察。
3. 玩家在2拍或4拍内用身体模仿动作。
4. 裁判翻到背面，根据评分表打分。
5. 根据分数调整状态。

### 7.1 分数判定

| 分数 | 判定 | 体验含义 |
| --- | --- | --- |
| 0-4 | 掉队 | 明显跟不上，产生慌乱或尴尬 |
| 5-6 | 勉强跟上 | 动作有相似处，但不稳定 |
| 7-8 | 成功跟上 | 基本进入队伍节奏 |
| 9-10 | 漂亮完成 | 熟练、自信、身体舒展 |

### 7.2 状态变化

| 条件 | 结果 |
| --- | --- |
| 得分7分以上 | 自信 +1 |
| 得分9分以上 | 自信 +2 |
| 得分4分以下 | 自信 -1 |
| 大幅度动作 | 体力 -1 |
| 体力为0 | 动作幅度项最高只能得0分或1分 |

## 8. 测试方案

### 8.1 第一轮：单人测试

目的：验证动作卡可读性、节拍压力和评分规则。

流程：

1. 玩家从2拍动作卡开始，连续测试6张。
2. 玩家再测试4拍动作卡，连续测试6张。
3. 每张卡记录得分、体力、自信变化。
4. 测试后访谈玩家感受。

观察重点：

| 问题 | 观察方式 |
| --- | --- |
| 玩家是否能快速理解动作图？ | 是否频繁询问动作含义 |
| 玩家是否感到节奏压力？ | 是否抢拍、慢拍、漏动作 |
| 2拍是否太简单？ | 是否大多数都轻松9分以上 |
| 4拍是否太难？ | 是否大多数低于5分 |
| 评分是否清楚？ | 裁判是否犹豫或反复解释 |

### 8.2 第二轮：双人同步测试

目的：验证广场舞中的“队伍感”和“同步压力”。

流程：

1. 两名玩家同时看同一张动作卡。
2. 两人同时模仿动作。
3. 分别评分，再计算平均分。
4. 如果两人都7分以上，队伍同步 +1。
5. 如果一人4分以下，记录是否产生掉队感或互相影响。

观察重点：

| 问题 | 观察方式 |
| --- | --- |
| 多人同时做是否更像广场舞？ | 玩家是否观察他人、互相带动 |
| 失败是否带来社交压力？ | 玩家是否笑场、尴尬、自我解释 |
| 队伍同步是否值得成为核心变量？ | 玩家是否关心整体整齐度 |

### 9.2 试玩后访谈问题

1. 你是在“跳舞”，还是在“完成动作测试”？

5. 成功时你感受到的是得分成功，还是跟上队伍的轻松感？
6. 如果加入其他玩家一起跳，会更好还是更混乱？

## 10. 第一版设计边界

第一版不要加入太多外层内容。暂时不加入：

- 复杂音乐风格
- 服装和角色成长
- 广场空间争夺
- 社交事件
- 完整关卡系统

第一版只验证核心循环：

> 看见动作 → 身体模仿 → 节拍压力 → 相似度评分 → 自信变化

如果这个循环成立，再扩展为多人广场舞、队伍同步、领舞变化、社交氛围和电子游戏实现。

## 11. 后续迭代方向

| 方向 | 可能加入的机制 |
| --- | --- |
| 队伍同步 | 多人平均分、整体整齐度、前排带后排 |
| 熟练成长 | 重复同一动作后降低难度或提高得分上限 |
| 体力管理 | 大幅度动作得分高但消耗体力 |
| 社交氛围 | 连续失败影响自信，队友鼓励可恢复 |
| 领舞变化 | 动作卡从固定序列变成临场变化 |
| 电子游戏映射 | 摄像头/手柄/键盘输入替代人工评分 |
