# 从生活建构完整游戏：方法论总图

> **文档性质**：总方法论合成稿（研究 + 教学共用）
> **版本**：v3.1-draft
> **日期**：2026-09-12
> **来源**：v2.1 六步流程 + 领域学习路径 + 2026-09-12「游戏世界」讨论 + 同日合轨
> **判断**：从生活经验到可玩系统的前半段早已成型；把最小互动循环拓展为游戏世界的后半段，至此可以命名、可教、可检验。两条半段接上之后，**从生活建构一个完整游戏的路径已经成型**。情感经验与领域学习不再并列为两条路径：它们是同一段有难度的生活过程的两面。

---

## 0. 此刻成型的是什么

此前方法强在「把生活收成可玩的东西」，弱在「把可玩的东西长成一个世界」。

- **前半段**（v2.1）：真实经验 → 结构分析 → 数据化抽象 → 挑战空间 → 最小可玩循环。
- **后半段**（2026-09-12）：挑战空间 → 场所物化 → 世界内容 → 审美叙事契约。缺的不是灵感，是把这一跳命名。
- **合轨**（同日）：取消「情感经验路径 / 领域学习路径」的并列。二者曾被写成两条桥，是教学上的分叉，不是经验上的两种本体。

接上之后，方法不再是「先做机制，再想办法包装成游戏」，而是一条**先冷凝、再展开**的生成链：

```text
生活是嘈杂的  →  抽出一个小到不能再小的循环
循环是贫瘠的  →  用它自己的变量把世界长出来
```

**完整游戏**在本方法里不是内容量，也不是商业体量。它是五件事同时成立：

1. 玩家反复做的事，来自一段有难度的真实生活过程。
2. 同一件事能以多种合法方式变难，而不是换成别的玩法。
3. 每一种难法都能站成一个地方，而不是停在参数表。
4. 这些地方共享一套世界规则，并用痕迹先于任务的方式说话。
5. 一种审美态度把多样性收成「同一个世界」。

缺任何一层，得到的是：体验片段、换皮关卡、参数包，或先写好的剧本。五层齐了，才是本方法所说的完整游戏。

---

## 1. 一句话

> 从一段有难度的生活过程里，取出那个小到不能再小的互动循环；再用它的变量制造不同的难法；让每一种难法自己要求一个地方；最后用一种审美态度，把这些地方认作同一个世界。

翻转只有一句：

> 不要先发明「有趣的世界」，再给它找玩法。  
> 要先让核心循环的变奏**要求一个地方**，再让这个地方**要求一段历史**。

---

## 2. 总生成链

方法有两个运动。前一个是**冷凝**（condensation）：把生活收成循环。后一个是**展开**（expansion）：让循环长成世界。实现（纸面 / 身体 / 引擎 / AI）是平行轨道，不是设计逻辑的中心。

```text
【运动 I · 冷凝】从嘈杂经验取出可玩的核
────────────────────────────────────────
一段有难度的生活过程
   排队、赶地铁、学帆船、钩针、一次争执、一次等待……
        ↓ 同一经验读两面
经验结构
   判断如何改变  ×  感受如何发生
        ↓ 抽出玩家反复做的事
最小互动循环  ←———— 方法的脊柱
   verbs + 判断 + 反馈 + 再试一次
   （判断在变，感受也在变）

【运动 II · 展开】让这个核自己长成世界
────────────────────────────────────────
        ↓ 抽出 properties
数据化系统
   变量 / 规则 / 输入输出 / 反馈
        ↓ 组合成局面
挑战空间
   同一循环的合法变奏
        ↓ 问：什么样的地方会自然逼出这种变奏？
场所 Place
   物化后的挑战（海峡，不是「第 3 关」）
        ↓ 问：谁会来、这里出过什么事、留下了什么痕迹？
世界内容
   残骸、人物、生计、禁忌、任务
        ↓ 问：这些场所共享什么感受、视觉语气、叙事态度？
审美叙事风格
   把多样性收束成一个世界
        ↕ 试玩
完整游戏
   循环仍在；玩家开始用那种方式看，并以那种方式感受这件事
```

多样性来自挑战空间；统一感来自审美契约。两者缺一不可。只有多样性，会变成关卡包；只有风格，会变成换皮。

## 3. 一条路径：有难度的生活过程

### 3.1 为何合

任何过程只要有难度，就会有学习：人会调整判断，下次看得不一样。  
任何学习只要真的发生，就会有情感：挫败、侥幸、羞耻、沉迷、如释重负，无论多少、无论大小。

所以「情感」和「学习」不是两种原材料，也不是两座桥。它们是**同一段有阻力的过程**被读出来的两面。游戏要的也正是这件事：自愿去碰一种不必要的困难（Juul）。方法的起点因此可以收成一个：

> 一段你经历过的、有难度的生活过程。

没有难度，就抽不出判断变化，也抽不出值得做成循环的感受，后面的挑战空间会是空的。

### 3.2 为何曾经分

v2.1 把它们写成两条路径，主要不是理论发现，而是**教学适配**：

高中夏校里，青少年的生活相对单一，很难取出丰富、可公开、可设计的情感事件。他们手头最现成的「有难度的过程」，往往是正在学的一项技能——帆船、钩针、滑板、摄影。领域学习专项（`domain-learning-to-game-system.md`）是为这个入口写的问题清单，不是第二条方法论。

大学课程、个人创作、研究案例则不必受这个限制。排队、赶地铁、一次争执，与学帆船是同类起点：都是有阻力的过程。差别只在阻力长在哪里（制度、时间、身体、技艺、他人），不在「这是情感还是学习」。

### 3.3 分析时仍读两面，但不再选边

合轨之后，学生不再选择「走情感」或「走领域」。对同一段过程，两面都要读：

| 面 | 核心问题 | 旧工具仍可用 |
|---|---|---|
| **判断** | 一开始如何看错？后来如何看对？失败后下次看什么？ | 新手/高手差异；OJAFA（Observe–Judge–Act–Feedback–Adjust） |
| **感受** | 什么触发？张力是什么？何时转折、高峰、余韵？ | 情感结构七步；情感原型卡片 |

最小循环必须同时扛住两面。抽掉判断，会变成情绪气氛、没有能动性；抽掉感受，会变成训练软件、没有余韵。*Celeste* 不是两条路径在世界层的汇合，而是合轨之后的正常形态：同一座山，既是攀爬判断的变奏，也是 Madeline 情绪的变奏。

验证也收成一句：

> 玩过之后，他们是否开始用你那种方式看这件事，并以那种方式感受它？

### 3.4 教学入口仍可从技能开始

理论一条；课堂上仍可按对象选**取样策略**：

- 生活经验较单一、需要可公开材料时：从正在学的技能取过程（夏校做法）。
- 材料更丰富时：从事件、关系、制度、身体处境取过程。
- 无论从哪取，分析格式相同，生成链相同。

领域学习文档降为**教学适配器**，不再与总方法并列。情感原型库仍是生长中的感受结构库，记录的是过程里读出的情感面，不是另一条路的入口。

脊柱仍是**最小互动循环**。它不是题材，不是世界观，也不是关卡列表。它是玩家将反复做的那件事：一组动词、一次判断、一种反馈、以及再试一次的理由。

Anthropy & Clark（2014）：循环 = 动词集；挑战 = 用这些动词写成的句子；世界 = 一本用同一种语法写成的书。先锁动词，再写句子，再集合成书。

## 4. 每一跳：问题、产出、检验、禁令

设计逻辑按跳推进。实现可以提前插入（纸面验证循环、引擎验证手感），但不能跳过某一跳的**判断**。

### 4.1 生活过程 → 经验结构

| | |
|---|---|
| **问** | 这段过程难在哪？动作、展开、判断如何变、感受如何走、发生在什么空间、牵涉什么对象？ |
| **产出** | 一张结构表：动作 / 过程 / 阻力 / 判断变化 / 情感轨迹 / 空间 / 对象 |
| **检验** | 判断变化和情感轨迹都能说清；没经历过的人也能听懂结构 |
| **禁令** | 不要从游戏类型或好看的世界出发；不要只写感受或只写步骤 |

情感七步（情境 → 命名 → 触发 → 张力 → 轨迹 → 机制线索 → 验证）和 OJAFA 都还在，作为同一张表里的读法，不是两套作业。

### 4.2 经验结构 → 最小互动循环

| | |
|---|---|
| **问** | 玩家将反复做的那一件事是什么？少到不能再少，少了判断或感受就会塌 |
| **产出** | 一句话循环 + 3–5 个动词 |
| **检验** | 抽掉装饰，循环仍能被玩、被失败、被再试；失败会改变下一次怎么看 |
| **禁令** | 不要用三个系统拼一个「看起来像游戏的东西」 |

这是方法的针眼。过不了这一关，后面所有世界都会漂。

帆船：读环境 → 转舵 / 调帆 / 选路 → 船的响应 → 再读。  
钩针：读图解 → 下针 → 看见织物对错 → 拆或继续。  
排队：等待中做微决策 → 队列状态变化 → 焦虑升降 → 再决定要不要换队。

三例格式相同。差别只是阻力分别长在风、针法、还是队列制度上。

### 4.3 循环 → 数据化系统

| | |
|---|---|
| **问** | 哪些要素必须变成变量，循环才能被程序（或规则）运行？ |
| **产出** | 变量表、规则、输入/输出、反馈、机制流程图 |
| **检验** | 3–5 个核心变量已够传达核；其余是候选，不是必需 |
| **禁令** | 不要把「能想到的设定」全部数据化 |

三个原问题仍然有效：某个要素能否表示为数据？什么动作改变它？基于它能设计什么挑战？

这一层同时也是给 AI 的接口。喂给模型的不应当是一段 prompt，而应当是一份**系统描述**：目标体验、核心循环、变量、规则、输入输出、反馈、挑战。系统化设计能力，是 AI 时代用游戏表达的基础能力——这一点与生成链兼容，但不替代生成链。

### 4.4 数据 → 挑战空间

| | |
|---|---|
| **问** | 同一循环有多少种合法的难法？它们彼此是什么关系——对比、因果、反复、歇息，还是只是越来越难？ |
| **产出** | 挑战维度表、挑战组合表、变奏之间的关系（不是默认的难度梯子） |
| **检验** | 挑战来自变量组合；失败后玩家知道下次看什么；两个挑战并置时说得出彼此为何相邻 |
| **禁令** | 不要为了「内容量」引入与循环无关的玩法；不要把「第 1、2、3 关越来越难」当成编排 |

公式不变：

```text
挑战 = 系统变量的特定组合 + 对玩家能力的特定要求
```

挑战空间是**集合**，不是斜线。Koster（2005）要的是同一模式上的变奏，不是难度滑条。Schmidt（1975）的变化练习也是横向取样，不是梯子。

完整游戏里，变奏一旦物化为场所，它们的关系首先是**戏剧—叙事的**：对比（海峡对背风湾）、因果（这里常出事，所以那边有救援站）、反复（同一股流，黄昏再读一次）、歇息（风暴之后的湾）、揭示（禁忌航线其实是一条更干净的回流）。这不是「按剧情排关」——按剧情排关反而更接近 Juul 所说的 progression 游戏，即设计师预先排好的序列。

**试玩递进**（单变量 → 双变量 → 综合）只保留为课堂原型的阅读顺序：用它检验循环是否成立。它不是世界的结构。若世界被做成梯子，场所会退化成「第 3 关」。

### 4.5 挑战 → 场所

| | |
|---|---|
| **问** | 这种压力若在真实世界出现，会是什么地形、气候、建筑、制度？ |
| **产出** | 场所推论表：每个挑战组合对应一个地方 |
| **检验** | 抽掉这个地方，这组挑战是否还站得住？站不住，说明地方是被要求出来的 |
| **禁令** | 不要先写「第 3 关」；不要先画旅游地图；不要让地方去「代表」一种情绪 |

**场所 = 物化后的挑战。** 阻力长在风上，地方是海峡；阻力长在制度上，地方可以是窗口、队伍、办公室。地方必须是这组约束的生态学位置，不能是寓言（这座山「代表」焦虑）。感受由在这个地方里做判断而发生，不由符号宣布。

帆船：横向强流 + 窄航道 → 海峡，不是「难度 3」。  
钩针：换色 + 拼接 + 读图错误累积 → 祖母方格 / 圣殿窗，不是「更多关卡」。  
排队：信息不明 + 插队 + 时间耗尽 → 只有一个窗口的深夜大厅，不是「焦虑关」。  
*旷野之息*：雨让攀爬失效 → 卓拉的常雨。可以反过来问：如果格鲁德住在雪山上，机制还成立吗？

Gibson 的 affordance、Newell 的个体×任务×环境、宫本式的 toy expansion，都在给同一句话背书：技能是在环境约束下被逼出来的；世界是这个玩具的生态位集合。

### 4.6 场所 → 世界内容

| | |
|---|---|
| **问** | 谁必须和这种约束长期相处？这里出过什么事？留下了什么痕迹？ |
| **产出** | 痕迹清单；人物/生计/禁忌；可选的任务（任务后于痕迹） |
| **检验** | 内容让玩家仍用核心循环做判断；新内容让玩家更像经历过这件事的人那样看 |
| **禁令** | 不要先写沉船爱情再回头找玩法；不要把痕迹直接做成收集清单 |

Fernández-Vara（2011）：世界用痕迹说话。沉船、折断的桅杆、错误的航标，是世界；救援任务是痕迹的可玩化。顺序不能反。

Jenkins（2004）的叙事建筑四用法对应后半段：唤起性空间 → 扮演的故事 → 嵌入叙事（痕迹）→ 涌现叙事（玩家自己的一次次尝试成为故事）。

场所并置之后，叙事空间可以写成交由玩家行动改写的**二维动态系统**，而不是一组预写好的静态事件：

```text
叙事时刻 = f(场所, 世界时间, 事件状态)
玩家行动 → 改写事件状态（有时也推移时间、改换场所）
```

| 轴 | 是什么 | 不是什么 |
|---|---|---|
| **空间** | 并存的场所；挑战的生态学位置 | 第 1、2、3 关 |
| **时间** | 世界相位：潮汐、昼夜、季节、窗口开放时段、等待 | 倒计时条；「玩到第 20 分钟播过场」 |
| **事件状态** | 这里出过什么事、是否可逆、别的场所是否读得到 | 预排的剧情节点 / 分支树里的 flag 伪装 |

静态事件：`进入海峡且剧情进度==3 → 播放沉船过场`。  
动态响应：`涨潮相位 + 海峡 + 曾在此失事 → 黄昏时救援站的船不在湾里`。事件作为**潜能**写在系统里，是否发生取决于状态，不取决于设计师排好的序号。

时间轴要和「时间压力」这个挑战变量分开。倒计时是循环里的一个 property；叙事空间的时间是**世界自己在走**，玩家可以等、错过、再来一次。事件状态则是世界的记忆：痕迹的可运行形式。

空间与时间会互相读对方。同一海峡，落潮可过、涨潮不可过，是时间改写空间约束。湾里的救援船是否出门，是海峡的失事状态改写另一场所。这就是戏剧关系（对比、因果、反复、歇息）的运行时：不是作者写在关卡表上，而是状态在两个轴上传播。

作者仍要写东西，写的是**潜能**（何种事件可能发生、何种条件、改哪些状态），不是故事。故事是玩家在空间×时间里走出来的那一条轨迹。Hartmut Koenitz 把这称作 System → Process → Product：设计系统，游玩是过程，叙事是产物。Emily Short 的 storylet / quality-based narrative 是同一结构的内容单位：带前置条件的片段，而不是剧本。

边缘要诚实：《Outer Wilds》的宇宙事件钉在 22 分钟时钟上，世界几乎不因你改写；变的是玩家的**认知状态**——同一时空，知道之后读法不同。那是二维叙事空间的认识论变体，不是反例。更典型的状态改写是《梅祖拉的假面》（三日时钟 × 角色行程 × 你救过谁）、《旷野之息》（完成神兽后卓拉不再长雨）。

### 4.7 世界内容 → 审美叙事契约

| | |
|---|---|
| **问** | 这些场所如果是同一个人的记忆，会是什么感觉？ |
| **产出** | 一个语气词 + 视觉/声音/叙事态度；一份「不合拍即删除」的清单 |
| **检验** | 换一种语气，世界内容必须大换，但生成方向不变——说明语气是契约，不是皮肤 |
| **禁令** | 不要用「奇幻/写实」代替语气；不要为风格引入新玩法 |

Carson（2000）：环境叙事需要一个 big picture——不是线性情节，而是这世界的总规则。审美契约就是这个 big picture。

*Dredge* 与《风之杖》循环相近（驾船、读海、赶时间/赶风），世界完全不同，因为契约不同：一个是民俗恐怖，一个是冒险卡通。同一生成链，不同契约，得到不同完整游戏。

Murray（1997）收成三句：场所提供 Immersion；挑战空间提供 Agency；审美契约提供 Transformation——玩家开始用那种方式看，并以那种方式感受这件事。

## 5. 课堂四问（后半段的可操作工具）

在挑战组合表之后加一张**场所推论表**。每做一个挑战，问四句。不准先写剧情。

1. **物化（Place）**  
   如果这种压力在真实世界里出现，它会是什么地形 / 气候 / 建筑 / 制度？

2. **痕迹（Trace）**  
   这种地方会留下什么失败或适应的痕迹？

3. **谁（Who）**  
   谁必须和这种约束长期相处？他们会发展出什么规则、禁忌、生计？

4. **语气（Tone）**  
   这些场所如果是同一个人的记忆，会是什么感觉？选一个，删掉所有不合这个感觉的内容。

5. **时空与状态（Space × Time）**  
   这个地方在哪些世界相位下会变？玩家怎样做会翻它的事件状态？哪个别的地方会读到这个状态？

鼓励大胆的判据不是「奇幻不奇幻」，而是：

1. 这个地方是否**必须**存在，才撑得住这组挑战？
2. 玩家是否仍在用核心循环做判断，而不是改玩收集 / 问答？
3. 新内容是否让玩家开始用那种方式看，并以那种方式感受这件事？

## 6. 和既有版本怎么叠

设计逻辑是一条链。教学和研究用不同分辨率去切它。

| 教学四步 | 研究六步（v2.1） | 本总图 |
|---|---|---|
| ① 一个生活感受 | Step 1–2 经验与结构 | 运动 I：有难度的过程 → 判断×感受 → **最小循环** |
| ② 数据化抽象系统 | Step 3 数据化 + 3.75 挑战空间 | 循环 → 变量 → 挑战空间 |
| ③ 引擎搭建 | Step 4–5 Unity + AI | 平行实现轨道（系统描述为接口） |
| ④ 游戏体验与世界拓展 | Step 6 游戏世界拓展 | 运动 II：挑战 → 场所 → 内容 → 审美契约 |

v2.1 的 Step 6 原为三层方向稿（机制变体 / 世界规则 / 叙事生长）。现收成四拍：

1. **机制变体** = 挑战空间取样
2. **场所物化** = 每组挑战必须对应一个地方
3. **世界规则** = 这些地方共享一套物理/文化定律（Juul：虚构如何提示规则）
4. **审美契约** = 统一语气；痕迹先于任务；玩家行为被世界记住

实现轨道的位置：最小循环一旦可陈述，就可以做纸面或身体原型；变量一旦可陈述，就可以写系统描述、交给引擎或 AI。**实现可以提前，判断不能跳步。**

## 7. 什么叫完整，什么叫失败

### 7.1 完整：五层同时成立

用帆船把五层写实（排队同格式，只换阻力所在）：

| 层 | 帆船 | 排队 |
|---|---|---|
| 循环 | 读海 → 转舵 / 调帆 / 选路 → 船的响应 | 读队 → 等待 / 换队 / 打听 → 队列变化 |
| 挑战空间 | 风力、阵风、洋流、航道宽窄、能见度 | 队伍长度、信息、插队、窗口开闭、剩余时间 |
| 场所 | 窄海峡、风口、背风湾、岛间通道 | 单一窗口的大厅、夜诊、安检口 |
| 世界内容 | 沉船、灯塔、领航员、夜航禁忌 | 黄线、叫号失灵、插队留下的空位、窗口里的人 |
| 审美契约 | 孤独的读海 / 民俗恐怖 / 科研日志，三选一 | 压抑的制度喜剧 / 冷淡官僚，二选一 |

钩针项目已经走过同一条链：针法循环 → 不同花片（挑战变奏）→ 祖母方格 / 圣殿窗 / 整张毯子（场所与世界）→ 珊瑚粉和实物图（审美收束）。

### 7.2 全链失败模式

前半段（冷凝失败）：

| 失败 | 症状 | 根因 |
|---|---|---|
| 题材化 | 帆船皮肤的赛车；排队皮肤的跑酷 | 没有抽出循环，只借了外观 |
| 教程化 | 按提示升帆；按提示选队 | 有流程，无判断 |
| 气氛化 | 很愁很美，但玩家没什么可做 | 有感受，无判断，循环扛不住 |
| 拼盘化 | 三个有趣系统互不相认 | 没有针眼，没有「少到不能再少」 |

后半段（展开失败）：

| 失败 | 症状 | 根因 |
|---|---|---|
| 换皮世界 | 先有海岛宝藏，循环仍是「开到那儿按键」 | 世界不是被挑战要求出来的 |
| 参数世界 | 只有风速 1、2、3，没有海峡、风口、背风湾 | 有挑战空间，没有场所 |
| 剧本世界 | 先写沉船爱情，再回头找玩法 | 叙事不从规则投射，Agency 会空 |
| 梯子世界 | 场所按「第 1、2、3 关越来越难」排列 | 把试玩顺序当成了世界结构；叙事关系被难度滑条替换 |
| 寓言世界 | 这座山「代表」焦虑 | 地方在宣布感受，而不是用约束逼出判断 |

深层转译在世界层的意思是——**玩家旅行的是挑战的生态学，不是旅游地图，也不是情感图解。**

## 8. 理论位置（按生成链引用，不按学科堆）

只在方法需要背书的那一跳引用。详细论述见 2026-09-12「游戏世界」讨论。

| 这一跳 | 理论 | 它允许我们对学生说的话 |
|---|---|---|
| 难度即起点 | Juul 自愿克服不必要的障碍；学习科学：难度产生反馈与图式 | 没难度，就没有可做的循环 |
| 循环与变奏 | Salen & Zimmerman 可能性空间；Koster 模式学习；Anthropy 动词→场景；MDA | 先锁动词；挑战是取样，不是灵感列表 |
| 编排而非梯子 | Juul 涌现/进程；Schell 兴趣曲线；Jenkins 叙事建筑；BotW 地标引力 | 完整游戏用戏剧—叙事关系编排场所；递进只是原型的阅读顺序 |
| 叙事空间 | Koenitz System–Process–Product；Short storylets；《梅祖拉的假面》空间×三日时钟 | 写潜能与状态，不写静态事件；故事是玩家在空间×时间里走出来的产物 |
| 挑战为何要环境 | Gibson affordance；Newell 约束模型；Schmidt 变化练习 | 抽掉环境还剩什么？什么都不剩，它还不是地方 |
| 规则如何变成世界 | Juul *Half-Real*；Meadows 系统与环境；宫本 toy expansion | 规则投射虚构；虚构让规则可想象 |
| 地方如何变成叙事 | Jenkins 叙事建筑；Carson 环境叙事；Fernández-Vara 索引叙事；Bogost 程序修辞；Murray 沉浸/能动性/变形 | 痕迹先于任务；风格是契约；规则在说理 |

艺术转化四手段（抽象化 / 结构化 / 放大 / 安全容器）仍然是冷凝运动的美学原理：游戏不是生活模拟，差异正是艺术。展开运动不取消这一点——世界仍是结构化之后的世界，不是把生活细节填回去。

与既有文献的对话位置不变：MDA、Iosup、Resonance 多是分析或描述共鸣从何而来；本方法给的是**从生活出发的处方性路径**。现在这条路径第一次覆盖到「完整游戏」，而不止于「可玩原型」；也不再把情感与学习写成两种入口。

## 9. 案例如何读

读法统一：**同一动词的生态位扩张**，不是先写世界观再找玩法。不再按「情感案例 / 领域案例」分列。

| 作品 | 循环 | 世界如何被要求出来 |
|---|---|---|
| *Dredge* | 驾船、下网、赶天黑 | 礁石 / 能见度 / 夜间恐慌长成不同群岛；民俗恐怖是契约 |
| 《风之杖》 | 扬帆 + 改风向 | 世界必须是海，岛必须是航线节点 |
| *Subnautica* | 游、氧气、扫描、造物 | biome = 挑战组合 = 叙事章节 |
| 《旷野之息》 | 爬、滑翔、体力、物理 | 雨/热/冷/火要求不同区域与文化适应 |
| *Outer Wilds* | 飞、读、在 22 分钟里理解 | 每颗行星是一套物理约束，遗迹长在物理里 |
| *The Witness* | 画线 | 区域是规则修饰符的教室；岛的冷静几何是契约 |
| *Celeste* | 冲刺 + 攀爬 + 体力 | 技能变奏与情感变奏钉在同一座山上——这是合轨后的范例，不是两条路的汇合 |
| *Portal* | 传送门 + 动量 | 测试房是变奏；实验室是「谁会造这些房间」的答案 |
| 超级马里奥 | 跳 | 冰/水/熔岩/云是跳的生态位；蘑菇王国是收束 |
| *Papers, Please* | 对照规则盖章 | 每天改规则 = 挑战变奏；冷战窗口是制度性场所 |

内部案例同读：钩针、帆船、排队。格式相同，只换阻力所在。

## 10. 尚未闭合的问题

路径成型，不等于研究做完。下列问题仍然开放，应进入下一轮实践，而不是用理论提前填死。

1. **阻力主要是社会或内心时，场所如何避免寓言化？** 海峡是洋流的生态学位置，清楚；「焦虑的山」容易变成符号。排队、争执、等待，需要更多非地形的场所实例。
2. **多人 / 社交循环**如何进入同一条链？Game Three 的最小循环是人与人的，场所可能是制度与场合，而不只是地形。
3. **审美契约的可教性**：语气如何在学生作业里被选择、被坚持、被检验，而不是最后贴一层美术。
4. **系统描述的粒度**：给 AI 的规格写到挑战空间即可，还是必须写到场所与契约，模型才不会自行发明世界？
5. **完整游戏的最小证据**：课堂里怎样才算「五层齐了」——一张场所推论表 + 一个可玩世界切片，是否足够作为研究证据？
6. **夏校适配器如何写回总方法**：领域学习问题清单里，哪些问句应并入统一结构表，哪些只在青少年课堂上使用？

## 11. 给学生的最短版

1. 从你经历过的一件**有难度的事**出发（学一门手艺、排一次队、赶一班车，都可以）。
2. 写出它怎么难、你后来怎么看、你一路怎么感受；从中取出玩家将反复做的那一件事。
3. 列出这件事里会变的性质，用它们组合出不同的难法。
4. 每一种难法都必须长成一个地方；先留痕迹，再决定要不要变成任务。
5. 选一种感觉，当这些地方的共同记忆；删掉不合这个感觉的东西。
6. 拿去给人玩。问的不是「好不好玩」，而是：他们是否开始用你那种方式看这件事，并以那种方式感受它。
