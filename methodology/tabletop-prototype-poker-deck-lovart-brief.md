# 来自生活的游戏设计：桌游原型扑克牌 Lovart 设计包

> 用途：给学生制作桌游纸面原型时使用。  
> 核心目标：让学生从生活体验出发，快速抽取“情绪、阻碍、资源、行动”，并转化为可玩的桌游规则。

---

## 1. 设计定位

这副牌保留标准扑克牌结构：四花色、A-K、大小王，共 54 张。它既可以像普通扑克牌一样洗牌、抽牌、分牌，也可以作为课堂中的游戏设计工具。

四个花色对应四类设计材料：

| 花色 | 类别 | 作用 |
|---|---|---|
| 红桃 | 情绪 / 关系 | 决定游戏想传达的核心感受 |
| 黑桃 | 阻碍 / 冲突 | 决定玩家面对的压力和矛盾 |
| 方块 | 资源 / 交换 | 决定游戏中被争夺、消耗或积累的东西 |
| 梅花 | 行动 / 机制 | 决定玩家可以做什么，以及玩法如何运转 |

建议牌名：**来自生活的游戏设计：桌游原型扑克牌**  
英文副标题：**Life-to-Game Prototype Deck**

---

## 2. Lovart 总提示词

可以先把下面这段作为整体设计提示词给 Lovart：

```text
Design a complete 54-card poker-style educational deck titled "来自生活的游戏设计：桌游原型扑克牌" with the English subtitle "Life-to-Game Prototype Deck".

The deck is for game design students. It helps them transform everyday life experiences into tabletop game prototypes. Keep the standard poker structure: hearts, spades, diamonds, clubs, A-K plus two jokers. Each card should still be immediately recognizable as a playing card.

Visual direction: clean educational design, modern tabletop prototype aesthetic, print-friendly, high readability, minimal but expressive icons, no fantasy decoration, no casino feeling, no childish cartoon style. Use restrained colors: heart red for emotion, spade dark blue/black for conflict, diamond amber/orange for resource, club green for action. White or warm off-white background. Use a consistent grid layout.

Each card layout:
1. Top-left and bottom-right: poker rank and suit.
2. Center: one large keyword in Chinese, with a smaller English keyword below.
3. Middle icon: simple symbolic illustration related to the keyword.
4. Bottom: one short design prompt in Chinese, maximum 18 Chinese characters.
5. Add a tiny category label: 情绪, 阻碍, 资源, 行动, or 变体.

Design all cards as one coherent system. Avoid long paragraphs. Avoid decorative clutter. Make the cards easy to print, cut, shuffle, and use in a classroom.
```

## 3. 牌面版式建议

每张牌建议使用统一信息层级：

1. **角标**：保留扑克牌数字和花色，例如 `A♥`、`7♣`。
2. **类别标签**：小字标注“情绪 / 阻碍 / 资源 / 行动 / 变体”。
3. **主关键词**：中文大字，例如“焦虑”。
4. **英文辅助词**：小字，例如 `Anxiety`。
5. **中心图标**：单色或双色图标。
6. **设计提示**：一句短问题，引导学生机制化。

建议尺寸：

| 项目 | 建议 |
|---|---|
| 牌尺寸 | 63mm x 88mm 标准扑克牌尺寸 |
| 出血 | 3mm |
| 安全边距 | 5mm |
| 正面背景 | 暖白或极浅灰 |
| 背面 | 四花色组成的抽象网格，中间放牌名 |
| 字体 | 中文用思源黑体 / Noto Sans SC；英文用 Inter / Source Sans |

## 6. 课堂使用方法

### 方法一：四牌生成法

每组学生抽：

1. 一张红桃：目标情绪
2. 一张黑桃：核心阻碍
3. 一张方块：核心资源
4. 一张梅花：核心行动

任务：20 分钟内做出一个可玩的纸面原型。

记录句式：

```text
我们要做一个关于 ______ 的游戏。
玩家想感受到 ______ ，但会遇到 ______ 。
游戏中最重要的资源是 ______ 。
玩家主要通过 ______ 来改变局面。
```

### 方法二：生活体验转译法

适合用于学生已经有生活素材，但不知道如何把它转成玩法时。这个方法的重点是：**先填写每个 Step 的问题，尽量从自己的生活经验中完成转译；如果没有思路或卡住，再使用卡牌辅助设计。卡牌不是替代生活经验，而是帮助学生把经验转成“情绪、冲突、资源、行动”四类游戏材料。**

建议时长：45-60 分钟。  
适合人数：个人或 2-4 人小组。  
产出：一张生活经验转译表 + 一个 5 分钟可试玩的纸面原型。

#### Step 1：写下生活场景（5 分钟）

学生先独立写一个真实或半真实的生活场景，要求包含：

1. **动作**：当时有人做了什么？
2. **过程**：这件事如何一步步展开？
3. **情绪**：过程中感受发生了什么变化？
4. **对象**：事情围绕人、物、信息、空间，还是某种规则？

避免只写抽象主题，例如“孤独”“竞争”“等待”。应写成具体场景，例如：

```text
我在食堂排队，前面的人一直犹豫点什么，后面的人又不断催促。我既着急，又不好意思催前面的人。
```

#### Step 2：先判断核心情绪，不急着抽牌（5 分钟）

学生用一句话回答：

```text
这个场景最想让别人体验到的感受是：__________
这个感受最强烈的瞬间是：__________
```

如果学生说不清楚，可以再抽一张红桃作为情绪参考；如果已经能说清楚，就不必抽红桃。红桃只用于校准，不用于替代学生自己的判断。

#### Step 3：抽 3 张牌补足游戏结构（10 分钟）

默认抽：

1. 一张黑桃：帮助定义核心阻碍
2. 一张方块：帮助定义核心资源
3. 一张梅花：帮助定义玩家行动

抽到的牌不是命令，而是问题。学生需要把牌翻译回自己的生活场景。

例如：

| 抽到的牌 | 不直接照搬 | 应该追问 |
|---|---|---|
| 黑桃：时间压力 | 不一定要做倒计时 | 这个场景中，什么东西让人觉得来不及？ |
| 方块：信息 | 不一定要做情报卡 | 谁知道、谁不知道、谁误会了什么？ |
| 梅花：竞价 | 不一定要拍卖金钱 | 玩家愿意付出什么来换取优先权？ |

#### Step 4：填写转译表（10 分钟）

```text
生活体验：__________
核心情绪：__________
情绪最强烈的瞬间：__________

黑桃牌 / 核心阻碍：__________
它在生活场景中对应什么？__________

方块牌 / 核心资源：__________
它在生活场景中对应什么？__________

梅花牌 / 玩家行动：__________
玩家可以通过什么动作改变局面？__________

最小规则：
玩家目标：__________
玩家每回合可以做：__________
资源如何变化：__________
什么时候产生压力：__________
什么时候结束：__________
```

#### Step 5：做一个 5 分钟纸面原型（15-20 分钟）

只允许使用低成本材料：纸、笔、便签、普通扑克牌、骰子、代币。原型必须能在 5 分钟内试玩，不追求完整美术。

最小原型必须回答四个问题：

1. 玩家要达成什么？
2. 玩家每轮做什么？
3. 哪个资源或状态在变化？
4. 哪个时刻最接近原生活体验的情绪？

#### Step 6：一分钟说明与快速试玩（10-15 分钟）

每组用一分钟说明：

```text
我们的生活场景是 ______。
我们想传达的核心情绪是 ______。
我们用 ______ 作为阻碍，用 ______ 作为资源，用 ______ 作为玩家行动。
这个游戏最像原生活体验的时刻是 ______。
```

其他同学试玩后，只反馈两件事：

1. 我是否感受到了目标情绪？
2. 哪个规则最有效，哪个规则最无关？

#### 教师判断标准

这个练习不以“游戏是否完整”作为主要标准，而看四件事：

1. 生活场景是否具体，而不是只有抽象主题。
2. 情绪是否有过程和转折，而不是单个情绪词。
3. 抽到的牌是否被转译，而不是被机械照搬。
4. 最小规则是否真的让玩家行动引发情绪，而不是只靠讲故事说明情绪。

### 方法三：机制替换法

同一个生活体验保留红桃、黑桃、方块，只替换梅花。  
目的：让学生看到“同一情感目标可以被不同机制表达”。

### 方法四：测试反馈法

试玩后让玩家选牌反馈：

1. 选一张红桃：这局最接近的感受。
2. 选一张黑桃：这局最大的压力来源。
3. 选一张梅花：最有效或最无效的机制。

## 7. Lovart 制作建议

1. **先做 5 张样卡，不要一次做 54 张**  
   建议先生成：A♥、4♠、5♦、7♣、大王。确认风格、字体、留白、可读性后再批量扩展。

2. **要求“同一模板批量替换内容”**  
   重点不是每张都画得很花，而是版式一致、文字清楚、可印刷。

3. **中文必须人工校对**  
   生成式视觉工具容易把中文做错。导出前逐张检查关键词和提示句。

4. **避免过度插画化**  
   这副牌是课堂工具，不是收藏卡。图标应辅助识别，不要抢走文字。

5. **保留普通扑克牌功能**  
   角标必须清楚，否则学生不能用它做抽牌、比大小、分组、随机化。

6. **先做打印版，再考虑精美版**  
   第一版建议黑白打印也可用。颜色只做辅助，不做唯一识别方式。
