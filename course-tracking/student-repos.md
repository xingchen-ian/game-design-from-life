# Student Project Repositories

> Course-level index for student projects using the "Game Design from Everyday Life" methodology v2.0.
> This file is maintained by the instructor/researcher, not by individual student teams.

## Purpose

This document keeps all student GitHub repositories and project metadata in one place. It is the entry point for checking student progress, locating each `agent-development-log.md`, and preparing cross-project analysis.

## Status Labels

- `Awaiting repo`: repo has not been collected yet.
- `Indexed`: repo has been opened and basic files were identified.
- `Concept documented`: original life experience, emotion, and mechanic are documented.
- `Prototype started`: code or playable materials exist.
- `Playable unverified`: a playable version may exist, but has not been checked.
- `Playable verified`: core loop has been checked.
- `Needs follow-up`: key files are missing or progress is unclear.

## Notes

- Student repositories should keep their own `agent-development-log.md`.
- This file should not duplicate every interaction log. It only records course-level metadata and current status.
- Private repositories require the instructor account to have access before they can be checked.
