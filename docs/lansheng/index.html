揽胜图两版对照

识典上至少有吴陈琰本与杨复吉跋《揽胜图谱》两系；定马映射不同，勿当成同一印本。

定马不要混

吴陈琰本正文写明一骰定马：么渔父、二羽士、三剑侠、四美人、五缁衣、六词客。金学诗《牧猪闲话》所记高兆定马是么词客、二羽士、三剑侠、四美人、五渔父、六缁衣。么、五、六三格不同。

《揽胜图谱》（杨复吉跋）格上亦见词客、羽士、剑侠、美人、渔父、缁衣六色，与吴本同为六色行旅图戏。该本定马映射尚未从正文对出，页上标「待核」。杨复吉跋本只是倾向高兆／昭代一系，不写成「即高兆本」。
