核心亮点

研究贡献

01

双路径框架

将“来自生活”明确拆成情感经验路径与领域学习路径：前者关注情感等价，后者关注认知变化、技能循环和反馈理解。

02

挑战空间设计

变量表本身还不是游戏。通过挑战维度和变量组合，将系统推导为关卡、任务、压力变化和学习曲线。

03

情感原型库

归纳并持续生长情感原型——绝处逢生、三顾茅庐、遗憾、惊喜等——作为情感经验路径的创意工具。

04

教学应用实践

方法论已形成问题清单、Google Form、AI-Agent辅助流程和课程证据，支持学生从真实经验进入原型开发。

05

实践驱动研究

每次设计实践既是作品生产，也是方法验证。研究与创作相互推动，在桌游、身体原型和数字游戏中持续迭代。

最新实践

设计实践矩阵

每一次设计实践，都是理论的验证与深化——从桌游、身体原型到数字游戏。

01

「排队」桌游

将排队的社会性体验转化为桌游——人际博弈、推挤竞争、道德抉择。情感原型：绝处逢生、遗憾、无奈、暗爽。

查看完整设计过程 →
02

帆船模拟器

领域学习路径的代表案例：新手以为"我要控制船"，高手知道"我要读取风"。读风→调帆→借力，形成观察-判断-行动-反馈循环。

了解领域学习路径 →
03

广场舞身体原型

退休女性广场舞的"跟上队伍"体验：动作模仿 + 节奏压力 + 相似度评分，验证非数字/身体活动如何进入方法论。

查看身体原型 →
04

Anxiety In Lines

教师同步项目：排队中的不确定等待、有限控制和封闭社交压力，以 NoP / GT / RWT 变量驱动排队管理与协商。
