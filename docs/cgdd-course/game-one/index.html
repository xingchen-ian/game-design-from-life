Mini-Project 1 · 无代码Mini-Project 1 · No Coding

用引导式问答，把一段有难度的过程变成可玩框架Turn One Difficult Process into a Playable Framework

Game One 刻意保持低技术：不写代码。你取一段真正经历过的、有难度的过程——争执、排队、学一项技能都可以——同时读出判断如何变、感受如何走，再把它收成最小循环。Game One is deliberately low-tech: no code. Take a difficult process you have actually lived — a fight, a queue, learning a skill — read how judgment changes and how feeling moves, then condense it into the smallest loop.

不要选「走情感」或「走领域」。两面都要读。讲义在 方法 页。 Do not choose emotion-led or domain-led. Read both faces. The handout is on the Method page.

Game One 路线图The Game One Roadmap

C1Framework
课程介绍与破冰；一条路总览；玩一个游戏，看它的循环是否同时扛住判断和感受。Course intro; the one-path method; play a game and ask whether its loop carries both judgment and feeling.
C2Framework
引导式创作工作坊：用问题把过程收成最小循环；AI 作为设计伙伴，不得替你选边。Guided-questioning workshop: questions condense a process into a loop; AI is a partner, not the one who picks a side.
C3Framework
用户测试：他们开始用你的方式看这件事，并以那种方式感受了吗？测试报告 + 迭代。User test: did they start to see it your way, and feel it that way? Test report + iteration.
