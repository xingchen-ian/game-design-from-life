夏令营成果

NYU Shanghai IMA Game Design 高中生夏令营 · 领域学习路径的完整落地：62 个可玩游戏、作品展览与学生 Showreel。

Camp Overview

从真实领域学习到可玩世界

2026 暑期夏令营把「领域学习路径」完整跑了一遍：学生从自己正在学习的真实领域出发（帆船、滑冰、烘焙、射箭、摄影、魔方……），拆解新手/高手的认知差异，把领域反馈转译成游戏反馈，最终在三天内制作出可玩的数字游戏。

Camp Journey

三天课程节奏

每次课都产出可展示材料，最后一天学生作品全部上线展览。

01

选择领域

记录自己了解或正在学习的领域，找出新手一开始看不见什么。

产出：领域学习采样表
02

拆解技能

比较新手和高手判断，画出观察、判断、行动、反馈、调整的技能循环。

产出：新手/高手差异卡
03

制作原型

用 AI-Agent 开发管线把领域对象、玩家行动、反馈信号做成最小可玩循环。

产出：挑战阶梯原型
04

展演验证

作品上线 Gallery 展览，同学互相试玩，观察是否开始使用领域判断方式。

产出：62 个可玩游戏 + Showreel
Student Works

62 个学生作品

领域分布：运动类最多（滑冰、骑马、越野跑、滑雪、射箭、攀岩、冲浪……），其次是烹饪、视觉艺术与帆船/风。

运动

  • 滑冰、骑马、越野跑
  • 滑雪、射箭、攀岩
  • 冲浪、潜水、骑行
  • 动物竞速

烹饪

  • 烘焙与蛋糕设计
  • 揉面手感
  • 烘焙节奏

视觉 / 艺术

  • 色彩与色相
  • 光与光谱
  • 描红、摄影曝光

帆船 / 风

  • 读风与调帆
  • 帆船生存

技能 / 乐器

  • 魔方还原
  • 乐器演奏

其他领域

  • 昆虫潜行、无人机飞行
  • 梦境环境、描红书法
  • 动物救援、文字世界
