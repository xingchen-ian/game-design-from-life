Summary Routes

之后做总结时，可以按三种路线组织

研究汇报路线

先讲研究问题与 V02.1 双路径框架，再用排队游戏、领域学习材料和学生案例说明方法如何被验证，最后回到论文贡献和下一步实证数据。

教学成果路线

先讲课程目标，再展示问题清单、Google Form、系统设计图、学生 repo 和 AI 协作日志，重点证明方法可教、可学、可评估。

活动/工作坊路线

先讲“从生活到游戏”的参与方式，再使用情感原型卡、扑克牌原型工具和身体原型案例，把成果呈现为可复用的活动包。
