先把世界拆成可游玩的节点，再决定哪些节点需要航线系统。

本页用于沉淀地理信息。每个地点先记录它在晚明海贸中的功能、主要货品、控制者或关键社群，以及可转化为游戏机制的判断。资料与判断分开标注，避免把设计推论误写成史实。

港口节点

港口不是单纯买卖点，而是权力、货物、风险和信息的交汇处。

资料 马尼拉 / Manila

西班牙在 1571 年建立殖民城市后，马尼拉成为太平洋白银与中国、东南亚货品交换的核心节点。中国商人，尤其福建商人，将丝绸、瓷器、漆器和加工品带到马尼拉，换取新西班牙白银。

功能
白银-亚洲商品转换港；西班牙菲律宾殖民行政中心。
主要货品
美洲白银、丝绸、瓷器、香料、漆器、棉布、奴隶与人口流动。
游戏判断
高利润、高制度风险；大帆船周期可作为年度事件。

来源：Manila galleon；History of Manila；Flynn & Giraldez 1995。

资料 澳门 / Macau

16 世纪中叶后，澳门成为葡萄牙人在中国沿海的重要居留和贸易节点，连接广州贸易、印度洋、马六甲、果阿、日本和欧洲网络。

功能
葡萄牙中国入口；中介贸易、传教、翻译和跨文化信息节点。
主要货品
中国丝瓷、印度洋商品、日本银铜、欧洲货物与军火。

来源：Macau 历史资料；葡萄牙亚洲贸易研究；Brook 1998。

资料 月港 / Yuegang

隆庆开海后，福建月港成为明朝允许民间海外贸易的重要出口口岸之一。它与漳州、泉州、福建海商和马尼拉贸易关系密切。

功能
合法化后的福建海外贸易出口口岸。
主要货品
丝织品、瓷器、纸、铁器、糖、日用手工业品。

来源：隆庆开海研究；Manila galleon 关于福建商人供货的资料。

资料 Cavite / 甲米地

Cavite 位于马尼拉湾，是大帆船出入、修造、装货的重要港区。大型远洋船无法完全等同于城市河港活动，Cavite 更像马尼拉海上系统的外港和造船区。

功能
大帆船港区、船坞、出发与抵达节点。
主要资源
船材、船工、补给、装卸劳力。

来源：Cavite City: Manila-Acapulco Galleon Trade。

资料 阿卡普尔科 / Acapulco

阿卡普尔科是马尼拉大帆船在美洲的核心终点。亚洲货物抵达后，经陆路转运至墨西哥城和韦拉克鲁斯，再进入大西洋贸易体系。

功能
新西班牙太平洋港；亚洲货物进入美洲与欧洲市场的入口。
主要货品
出港多为白银；入港多为中国和亚洲奢侈品。

来源：Manila galleon；新西班牙贸易资料。

资料 马六甲 / Malacca

马六甲控制印度洋与南海之间的重要海峡位置。葡萄牙在 1511 年占领马六甲后，它成为葡萄牙亚洲网络的关键节点之一，但后来受到荷兰等势力挑战。

功能
海峡中转、香料和印度洋商品集散。
主要货品
香料、印度洋商品、中国货、东南亚物产。

来源：马六甲海峡与葡萄牙亚洲贸易研究。

货品

货品不只是价格，还决定派系、技术、风险和文化传播。

白银

来源包括美洲和日本，是大额贸易、税收和财富储藏的重要媒介。

机制：货币、税负、贷款、军费、银荒

丝绸与丝织品

中国高价值出口品，马尼拉贸易中常被白银购买。

机制：订单、品质、运输损耗、奢侈品需求

瓷器

中国外销商品之一，适合连接景德镇、内陆转运和海外审美需求。

机制：定制图样、易碎货、批量合同

香料

东南亚与印度洋网络的重要商品，欧洲竞争强烈。

机制：垄断、战争、转运、港口封锁

日本银铜

日本矿产在 16-17 世纪东亚贸易中重要，后续受日本对外政策影响。

机制：政策变化、海商中介、金银比价

船材与补给

菲律宾、东南亚和中国沿海提供船材、粮食、水手、修船和港口劳力。

机制：航行准备、船坞、劳力短缺、台风季
