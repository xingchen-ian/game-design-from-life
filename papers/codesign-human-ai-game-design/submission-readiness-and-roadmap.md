- **自引率约 34.6%**（2024–2025 偏高）：投稿时引用期刊自身论文要适度、自然，不要为了"显得契合"而过度堆砌

2026 年已出现 special issue（如 "Autoethnographies of social design practices"），另有征稿中（如 "Designing Democratic Innovation"）。**建议到期刊主页 "Calls for papers" 栏目查看是否有更契合的专刊**——专刊投稿通常主题聚焦、见刊更快。

## 第三部分：缺口分析（诚实版）

> 你是首次投稿，以下缺口按**严重度**排序，逐项给出"现状 → 缺口 → 补救"。

### 🔴 A. 数据分析未做（最致命）

- **现状**：agent 日志、系统图、GitHub 产物都**存在**，但没有被**编码和分析**
- **缺口**：论文的 Findings 章节现在是空的。`analysis-framework.md` 有编码类别，但**从未试跑过**；没有研究发现、没有主题、没有证据支撑任何 RQ
- **补救**：这是 Phase 2 的全部工作（见路线）。**没有这一步，其他都免谈**

### 🔴 B. 文献综述方向不匹配

- **现状**：现有 32 篇综述是"游戏机制×生活体验"（为方法论论文服务）
- **缺口**：CoDesign 需要的是"**协同设计×人机协作×游戏设计教育**"综述——Sanders & Stappers、Visser et al.、Brandt et al.、human-AI collaboration、boundary objects、AI in design education 这条谱系几乎空白
- **补救**：Phase 1 专门重建文献综述（不是推翻旧的，而是为这篇论文新立一支）

### 🟡 C. 英文学术写作

- **现状**：USER.md 已记录——无系统英文学术写作训练，惯用"中文构思 + AI 辅助英文升格"
- **缺口**：CoDesign 要求严格的学术英文（双盲审稿，语言质量直接影响编辑初审与审稿人印象）
- **补救**：中文起草 → AI 英文升格 → 建议**额外请一次专业学术润色**（或让合作者/母语者通读 Discussion 章节）

### 🟡 D. 数据完整性

- **现状**：course-tracking 存在已知缺口
- **缺口**：P05/P06 仓库缺失；One More Sip 日志滞后于实现；Wuwei 概念漂移未经学生确认
- **补救**：投稿前补齐或明确"本研究仅采用数据完整的案例"（The Darkroom、帆船、Coaster Carnage 等即可支撑，不必全用 7 个）

### 🟡 E. 定性研究严谨性

- **现状**：分析方法已设计，但严谨性未规划
- **缺口**：定性研究（主题分析/扎根）需要交代：编码流程、编码者、信度（是否多人编码/交叉核对）、效度（三角验证）
- **补救**：方法章节明确写出"三证据对照"作为效度策略；若单人编码，需说明"研究者反思（researcher reflexivity）"与"审计追踪（audit trail）"

### 🟢 F. 伦理合规（需自查）

- **缺口**：学生（含未成年人？高中生夏令营）作品、日志、截图用于发表，是否有**知情同意**？CoDesign 会要求伦理声明
- **补救**：核对夏校/课程是否有作品使用授权；投稿时在 Ethics Statement 中如实说明

### 🟢 G. 投稿流程操作

- **缺口**：ScholarOne 系统、双盲匿名化处理（删去能识别作者/机构的信息）、cover letter、格式排版
- **补救**：Phase 4 专门处理；双盲要求全文去掉"Ian/NYU 上海"等可识别信息，自引改为第三人称

## 第四部分：后续步骤路线（五阶段）

```
Phase 0 决策核查 → Phase 1 文献奠基 → Phase 2 数据分析 → Phase 3 写作 → Phase 4 润色提交 → Phase 5 审稿
   (约1周)          (约2周)         (约2-4周·最重)     (约2-3周)      (约1周)        (3-6个月)
```

### Phase 0：决策与核查（约 1 周）

| 任务 | 产出 |
|------|------|
| 查期刊主页 Calls for papers，确认投常规栏目还是 special issue | 投稿目标锁定 |
| 核对数据完整性（P05/P06、One More Sip、Wuwei 确认） | 可用案例清单 |
| 确认学生作品知情同意/授权 | 伦理声明素材 |
| 锁定可用案例集（建议：The Darkroom + 帆船 + Coaster Carnage + 1–2 个高中生案例） | 案例筛选 |

### Phase 1：文献奠基（约 2 周）

| 任务 | 产出 |
|------|------|
| 精读 An & Oogjes 正式版 + Lee-Remond 全文 | 两篇精读笔记（已有基础） |
| 检索并建立 co-design 谱系综述（Sanders & Stappers 2008 / Visser 2005 / Brandt 2008） | Related Work 素材 |
| 检索 human-AI collaboration / boundary objects / AIGC 设计流程（Huang et al. 2024） | 理论对话素材 |
| 撰写 Related Work 初稿（中文） | 章节初稿 |

### Phase 2：数据分析（约 2–4 周，最重的活）

| 任务 | 产出 |
|------|------|
| 用 analysis-framework 编码选定案例的 agent 日志（先 2–3 个案例试跑） | 编码试跑 + 框架修订 |
| 三角验证：系统图 ↔ 日志 ↔ 产物 | 证据链 |
| 主题归纳：分工协议 / 决策归属 / AI 角色谱系 / 概念漂移 / 系统描述形态 | Findings 素材 |
| 整理关键引文（日志原文）作为 Findings 佐证 | 可引用证据 |

### Phase 3：论文写作（约 2–3 周）

| 任务 | 产出 |
|------|------|
| 中文起草全文（Intro / Related Work / Methods / Findings / Discussion / Conclusion） | 中文完整稿 |
| AI 辅助英文升格 + Ian 审核意思 | 英文初稿 |
| 制作图表（协作流程图、分工协议图、编码结果表、案例截图） | 图表 |
| 专业学术润色（建议） | 润色稿 |

### Phase 4：润色与提交（约 1 周）

| 任务 | 产出 |
|------|------|
| 双盲匿名化处理 | 匿名稿 |
| 按 CoDesign 格式排版（提交时确认字数与格式要求） | 终稿 |
| 撰写 Cover Letter（强调与期刊 fit、原创贡献、为何适合 CoDesign） | Cover letter |
| ScholarOne 提交 | 完成投稿 |

### Phase 5：审稿周期（3–6 个月，心理预期）

- 编辑初审：约 2–4 周（可能 desk reject）
- 同行评审：约 2–4 个月
- 结果：Accept / Minor Revision / Major Revision / Reject
- **建议心态**：首次投稿按 Major Revision 预期，视为正常流程而非失败

## 第五部分：风险评估与缓解

| 风险 | 等级 | 缓解策略 |
|------|------|---------|
| 编辑认为"不够协同设计"（theme misfit） | 中 | 全文以 human-AI collaboration / boundary objects 为主线，co-design 词汇贯穿；cover letter 明确点出与期刊 scope 的契合 |
| 数据严谨性被质疑（定性信度） | 中 | 方法章节交代编码流程 + 三角验证 + 审计追踪；必要时双人交叉编码 |
| 英文写作质量 | 中 | 中文起草 + AI 升格 + 专业润色三层保障 |
| 伦理合规（学生作品授权） | 中高 | Phase 0 必须核实，否则不能投 |
| 与已发表论文定位冲突（An & Oogjes / Lee-Remond） | 低 | 已在 framework.md 第 1.3 节做了差异定位表，写作时明确"填补空缺"而非重复 |

## 第六部分：立即可做的 3 件事（本周）

1. **查期刊主页 Calls for papers**——确认是否有契合的 special issue（影响投稿路径与节奏）

## 总结（一句话）

你的资产（双夏校数据 + 方法论 + 材料）已经足够支撑一篇 CoDesign 论文的**原料**；真正的缺口是**还没做数据分析、文献综述方向要换、英文写作需要流程化**——这些都可通过 Phase 1–3 系统补齐。最大风险不是能力，而是**伦理合规**和**定性研究严谨性**这两个首次投稿者容易忽略的细节。
