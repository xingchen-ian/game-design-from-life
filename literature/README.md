## 文献记录格式

每篇文献笔记包含以下字段：
- **基本信息**：标题、作者、年份、出处、DOI/链接
- **核心论点**：文章的主要贡献和观点
- **方法论**：研究采用的方法
- **与本研究的相关性**：如何支撑"来自生活的游戏设计"方法论
- **可引用内容**：关键段落或观点
- **后续行动**：获取全文、深入阅读章节等
