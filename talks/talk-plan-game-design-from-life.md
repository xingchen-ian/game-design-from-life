## 0. 核心命题与论证链

> **好的游戏设计灵感，不是来自其他游戏，而是来自生活本身——游戏是艺术，创新源于生活。**

```
研究空白（机制库多、体验路径缺）
  → 方法论（双路径：情感经验 + 领域学习）
  → 证据（排队案例 + 学生作品，RtD 范式）
  → 贡献对话（与 MDA / Iosup / Resonance 对话）
```

一句话版：游戏设计领域有丰富的机制库与情感测量工具，但缺少一条**从生活体验出发、可教授、可复用的正向设计路径**；本演讲呈现这条路径及其真实实践证据。

## 1. 研究定位（学术会议语境）

### 1.1 研究空白（为什么值得听）

| 现有工作 | 覆盖 | 缺口 |
|---------|------|------|
| MDA（Hunicke et al., 2004） | 机制→体验的**逆向分析** | 无"体验→机制"正向设计方法 |
| 游戏设计模式（Björk & Holopainen, 2005） | 机制层面模式库 | 不涉及情感/生活来源 |
| 情感设计框架（Iosup et al., 2023） | 情感适配原则 | 描述性，无处方性流程 |
| Resonance（Väkevä et al., 2026, CHI Best Paper） | 确认共鸣源于个人经验连接 | 解释性，未给出设计路径 |
| 自传体游戏（Anthropy, Quinn, Green） | 可行性个案 | 特例，不可教授 |

**核心空白**：从生活体验出发的**处方性、可教授**设计路径。

### 1.2 证据范式

- Research through Design（Zimmerman et al., 2007）：设计产物+设计日志=中层知识载体
- 三证据对照：Canva 系统设计图 ↔ GitHub 产物 ↔ agent 开发日志

## 3. 90 分钟版本（拓展 = 三模块 × 30 分钟）

### 模块 A（0–30min）：问题与方法
- 开场钩子（2 个生活瞬间：排队 + 徒步）
- 研究背景深化：游戏设计研究谱系（机制→体验→情感→意义）
- 文献对话更充分：MDA / 模式库 / 4 Keys / Iosup / Ekanayake / Resonance
- 问题定义清晰化：处方性 vs 描述性；"可教授"意味着什么
- **轻互动**：听众分享一个"被游戏打动是因为想到自己生活"的经历

### 模块 B（30–60min）：案例深挖（核心证据）
- 排队案例完整复盘（15min）：设计日志→情感结构→变量→原型→试玩→迭代（展示**过程**而非结果）
- The Darkroom 学生案例（10min）：读 2–3 条 agent 日志，展示 AI 协作 + 学生设计决策分离
- 领域学习路径（5min）：帆船"读风"——新手 90 度帆角误解→读风/借力/之字航行
- **轻互动**：举手"你有没有过'照片没拍出当时感受'？"→ 引入 Darkroom

### 模块 C（60–90min）：方法、贡献与讨论
- 方法论完整呈现（15min）：六步流程 + Step 3.5 + 四手段；学生作品快览（Wuwei / One More Sip / Coaster Carnage / 广场舞原型）
- 贡献与局限（10min）：与文献对话、RtD 定位、坦诚局限（样本小、单一文化、情感等价未量化）
- 开放讨论 Q&A（5min+）
