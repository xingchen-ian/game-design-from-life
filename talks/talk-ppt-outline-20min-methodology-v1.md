## 设计原则（浅色极简风）

- 白底 `#FFFFFF`，正文深灰 `#333`，标题黑 `#111`
- 单色点缀：主色一个（建议 `#2563EB` 蓝，用于强调词/箭头/环节编号）
- 每页 ≤ 3 个要点、≤ 6 个词的大标题；其余交给截图
- 截图统一圆角白边，标注来源（如"学生 Canva 系统图 · P00"）
- 过渡页不用花哨动画，用「环节编号 + 环节名」的大字页（如 `01 开场`）

### 01 开场钩子（0.5–2min）— 2 页

**P2 两个生活瞬间（钩子页）**
- 左图：排队场景照片（或 P00 截图开场版）— 问："谁排队时焦虑过？"（举手）
- 右图：一张"拍糊/拍暗"的照片 — 问："谁有过'照片没拍出当时感受'的时刻？"
- 页面底部一行：*这两个瞬间，都变成了游戏。*
- 素材：排队照片（待找/可生成）、P03 截图（曝光对比）
- 备注（过渡）：*为什么我要从一个游戏设计演讲，讲排队和拍照？……因为我认为好的游戏设计灵感，不是来自其他游戏，而是来自生活本身。* → 点题

**P3 核心命题**
- 一句话：**好的游戏设计灵感，不是来自其他游戏，而是来自生活本身。**
- 三个关键词：生活 → 情感 → 机制
- 视觉：居中大字 + 三词横向箭头
- 备注：抛出命题后立即给出论证路线（"接下来 15 分钟：为什么是空白 → 我的方法 → 两个真实证据"）

---

### 02 背景与空白（2–5min）— 3 页

**P4 研究空白：机制库多，体验路径缺**
- 左侧：现有工具箱（MDA 逆向分析 / 模式库 / 情感测量）
- 右侧：缺口 —— 从**生活体验出发**的**正向、可教授**设计路径
- 视觉：左右分栏，"缺口"用红色/橙色标注
- 素材：纯文字排版 + 文献脚注（Hunicke 2004; Iosup 2023; Väkevä 2026）
- 备注：点明听众可能的疑问"这些工具不是够用了吗？"——不够，因为它们都是**描述性/逆向**的

**P5 现有方法谱系（一页图）**
- 时间线/谱系图：MDA（机制→体验）→ 模式库（机制层）→ 4 Keys（情绪分类）→ 情感框架 Iosup（描述性）→ Resonance Väkevä（解释"共鸣来自个人经验连接"）
- 每项一句话 + 箭头指向共同的"空白"位置
- 素材：自制谱系图（PPT 内绘制）
- 备注：特别强调 Resonance（CHI 2026 Best Paper）——*最强的玩家体验证据，恰好证明"游戏有意义常因连接个人生活"，但作者没有给出设计路径——这就是我们的位置。*

**P6 问题陈述**
- 研究问题：如何把生活体验转化为游戏机制？**可教授**意味着什么？
- 两个分问题：①情感如何结构化为机制？（情感经验路径）②领域知识如何结构化为挑战空间？（领域学习路径）
- 视觉：一个问句大字 + 两个分路径标签
- 备注（过渡）：*为了回答这个问题，我先讲方法，再给证据。*

---

### 03 方法论框架（5–8min）— 3 页

**P7 方法总览：双路径**
- 总方法论图：生活体验 →（路径A 情感经验 / 路径B 领域学习）→ 游戏机制
- 路径A：生活事件 → 情感结构 → 游戏机制
- 路径B：学习过程 → 认知/技能结构 → 挑战空间 → 游戏机制
- 视觉：单页双分支图
- 备注：点明本次演讲证据覆盖路径A（排队、摄影、学生作品）；路径B 在 90 分钟版展开（帆船/徒步）

**P8 六步流程 + Step 3.5**
- 流程图：①生活感受 → ②情感原型 → ③数据化抽象 → **3.5 数据结构图** → ④Unity 搭建 → ⑤AI 辅助 → ⑥世界拓展
- 视觉：横向流程图，Step 3.5 高亮
- 备注：强调 3.5 步——*把模糊感受变成"变量表"，是整条路径最关键的一跃*（为排队案例埋伏笔）

**P9 艺术转化四手段**
- 抽象化 / 结构化 / 放大 / 安全容器（四宫格，每格一句话+一个例子）
- 例：排队焦虑 → 抽象为时间压力（抽象化）；放大为限时购票（放大）；安全容器=游戏内试错
- 备注：说明这回答"为什么不直接复刻生活？"——艺术需要转化，不是搬运

---

### 04 证据一：排队案例（8–14min）— 4 页（全篇核心）

**P10 生活瞬间：排队焦虑**
- 场景照片/描述：队伍不动、别人插队、时间流逝
- 情感结构分析表（触发/张力/转折/高峰/余韵）—— 一行式呈现
- 素材：排队照片 + 情感结构表
- 备注：*排队为什么让人焦虑？因为你的命运不掌握在自己手里。* 这是情感结构的第一步

**P11 数据化抽象：三个变量**
- 核心变量表：`NoP` 前方人数 / `GT` 剩余时间 / `RWT` 每个 NPC 随机等待时间
- 胜负条件：`NoP==0 && GT>0` 赢；`NoP>0 && GT<=0` 输
- 视觉：变量表 + 条件公式，右侧配生活↔变量对应注释
- 备注：*注意这里做的事——把"焦虑"翻译成了三个可以放进 Unity 的变量。* 引用"数据化抽象可教"的研究洞察

**P12 数据结构图（Step 3.5 产物）**
- 三列布局：世界状态（队伍/时间/等待）/ 玩家动作（前进/说服/让位）/ 资源（NoP/GT）
- 素材：P00 Canva 系统图 `course-tracking/canva-screenshots/P00-anxiety-in-lines.png`
- 备注：展示设计者（我）当时画图的过程——系统图是"设计合同"，后面写代码都照它来

**P13 游戏与迭代**
- 游戏截图：`docs/assets/course-screenshots/P00-anxiety-in-lines.png`
- 一句试玩迭代故事：从"只有前进键"到"说服/让位"的决策空间（时间充裕可展开 1–2 次迭代）
- 视觉：截图大图 + 迭代箭头
- 备注（过渡）：*一个主案例不够——这个方法能不能被别人学会？我们在一门 NYU 暑期课里让 30 多个学生用了它。*

### 05 证据二：学生作品（14–17min）— 3 页

**P14 The Darkroom：生活瞬间**
- 生活瞬间：摄影"拍不出所见"——太暗、太亮、长曝光变成光迹
- 情感结构一行式：期待 → 落差 → 重新理解
- 互动（可选）：举手"谁有过照片没拍出当时感受？"（若开场已举过则跳过）
- 素材：曝光对比照片（P03 素材）
- 备注：*这门课的学生 Boyan 也有这个体验，他把它做成了一款游戏。*

**P15 转译：曝光状态 + 光迹机制**
- 系统图：`course-tracking/canva-screenshots/P03-the-darkroom.png`
- 核心机制：`ES` 曝光状态（欠曝0/正常1/过曝2）+ `LT` 光迹 → 快门下移动留光，快门释放光迹变地形
- 视觉：系统图 + 2–3 张游戏截图并排
- 备注：*注意"欠曝/过曝"如何变成三种不同的玩法规则——这正是情感等价转换的教科书例子。*

**P16 过程证据：agent 日志 = RtD 证据**
- 展示 2–3 条 `agent-development-log.md` 摘录（如"今天把光迹从装饰改为地形"的决策记录）
- 三证据对照小图：Canva 系统图 ↔ GitHub 产物 ↔ 日志（51 脚本 / 72 次交互）
- 备注：*我们要求学生记录每一次 AI 协作，这些日志让"设计决策"和"AI 执行"可分离——这就是 Research through Design 要求的过程证据。* （Zimmerman 2007）

### 06 贡献与对话（17–19min）— 2 页

**P17 贡献**
- ①一条**处方性**设计路径（补 Resonance 的描述性缺口）
- ②双路径可教授方法（情感经验 + 领域学习），有真实课堂证据
- ③RtD 范式下的过程证据方法（三证据对照）
- 视觉：三个贡献卡片
- 备注：逐一回到开场空白页，形成闭环

**P18 与现有工作对话**
- MDA（逆向 → 我们正向）/ Iosup（情境依赖 → 我们给出流程）/ Resonance（解释共鸣 → 我们教怎么制造共鸣）
- 视觉：对比表（现有工作 | 它做什么 | 我们补什么）
- 备注：*不是否定前人，而是补上从体验到机制那缺失的一段。*

## 开场钩子建议（说明）

- **20 分钟版：排队 + 摄影**（推荐）
  - 排队 = 主案例（P10–P13 深讲），开场即埋主证据伏笔
  - 摄影 = 学生案例（P14–P16），开场即预告"可教授"这一核心卖点
  - 两者都是**人人都有的生活体验**，举手互动自然；且对应两条证据线，结构呼应
- **90 分钟版：排队 + 徒步**（保持 talk-plan 默认）
  - 徒步对应领域学习路径（Step 3.5 案例），在 90 分钟版有完整模块展开
